# kathrynrbrink.com

Personal professional website for Kathryn Brink, published with GitHub Pages.

## Editing the site

- Update content in the relevant HTML page. Primary pages are Home, Services, Work, About, Publications, and Contact.
- Work includes a detailed BioBuilder case study in `work-biobuilder.html`.
- Change colors and typography using the variables at the top of `styles.css`.
- Replace the placeholder CV link after adding the PDF to this repository.

The site uses plain HTML and CSS and has no build step or external dependencies.
